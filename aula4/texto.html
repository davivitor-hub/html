Porque é importante

Muita gente aprende HTML decorando tags: “quero negrito, uso < b>; quero itálico, uso < i>“. Funciona visualmente, mas ignora um detalhe importante: HTML não é
uma ferramenta de formatação visual, é uma linguagem de estruturação semântica de conteúdo . O CSS cuida da aparência; o HTML cuida do significado.
